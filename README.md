# Hotel Santa Prisca Website

Responsive website developed for a local hotel business.

## Features

- Responsive layout
- Spanish and English versions
- Contact and location sections
- Basic SEO setup
- Image optimization
- Published on a custom domain

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap
- cPanel
- Git

## What I learned

- Building a real website for a client/business context
- Organizing static website files
- Improving responsive design
- Deploying a website to shared hosting
- Configuring basic SEO files such as sitemap and robots.txt
